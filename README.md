# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 Project Overview

Heart Disease Prediction is a Machine Learning project that predicts the likelihood of heart disease based on patient health-related data. It uses Python and the Random Forest Classification algorithm to analyze medical attributes and generate predictions.

The project demonstrates how Machine Learning can be applied to healthcare data analysis and predictive modeling.

## 🎯 Project Objectives

- Analyze patient health data.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify important features affecting predictions.
- Build a Machine Learning classification model.
- Predict the likelihood of heart disease.

## ✨ Key Features

- Data preprocessing and cleaning.
- Exploratory Data Analysis (EDA).
- Data visualization.
- Feature analysis and selection.
- Random Forest Classification.
- Model evaluation.
- Interactive prediction interface using Streamlit.

## 📊 Dataset Information

The project uses a heart disease dataset containing 10,000 records.

The dataset includes patient health-related attributes such as:

- Age
- Chest Pain Type
- Cholesterol
- Resting ECG
- Other health-related features

**Target Variable:** `heart_disease`

## 🤖 Machine Learning Model

The project uses the **Random Forest Classifier**, an ensemble learning algorithm that combines multiple decision trees to perform classification.

The model development process includes:

1. Data Loading
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Train-Test Splitting
6. Model Training
7. Model Evaluation
8. Model Saving

## 📈 Model Evaluation

The model can be evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score

## 💻 Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/shivamprajapati10/Heart-Disease-Prediction-Using-Machine-Learning.git
```

**Step 2: Navigate to the project folder**

```bash
cd Heart-Disease-Prediction-Using-Machine-Learning
```

**Step 3: Install required libraries**

```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit
```

**Step 4: Run the Streamlit application**

```bash
streamlit run app.py
```
